# Trade records (paper + practice)

Exports of everything ChartLab stored, one folder per export date. All paper / practice — no real-money orders.

| File | Content |
|---|---|
| `swing_closed.csv` / `swing_open.csv` | Swing-picks paper portfolio (closed trades; open positions with unrealised P&L at export) |
| `bots_trades.csv` | Paper bots (Morning Edge, Gann, Daily Plan, NG), one row per trade, net after charges |
| `manual_paper_trades.csv` | Own trades in the 📝 Paper tab (live option quotes), incl. archived accounts |
| `practice_journal.csv` | Replay / practice trades (index points, no option costs) |
| `paper_all_legs.csv` | Every partial exit of every paper trade |
